Conflict Detector

TRB_PluginConflictDetector

Read-only scanner that finds hook overlaps, command collisions, shared databases, duplicate DLLs, API mismatches and known plugin issues.

Features

  • Inventories hooks, commands, timers, shared databases and third-party DLLs across the other plugins in ArkApi/Plugins.
  • Writes a severity-tagged report (CRIT / WARN / INFO).
  • On-demand: scans at startup and when an admin runs conflicts rescan. No timer, tick callback or hooks between scans.
  • Game thread only takes a sub-millisecond snapshot; analysis runs on a worker thread.
  • Results show only on the admin's own screen, with configurable colours and display mode.

Commands

conflictsSeverity summary of the last scan
conflicts allInclude info-level findings
conflicts hooksHooked-function call order
conflicts plugin <Folder>Per-plugin inventory and findings
conflicts rescanNew snapshot; run after loading/unloading plugins
conflicts stats / helpTimings (and whether TRB_Core is linked), help

Configuration

Command name configurable (CommandName, default conflicts). Display settings in ArkApi/Plugins/TRB_PluginConflictDetector/config.json.
