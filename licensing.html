How licensing works

Free plugins need no key. Paid plugins use a perpetual licence: you pay once and may keep using the version you bought, and updates we release, for as long as we support it.

One licence per game

ASE and ASA are separate products and are sold separately.

Getting your key

  1. Buy the plugin. Checkout is handled securely by our payment processor.
  2. Join our Discord server.
  3. Run /license register with TRB_SupportBot and give your server's machine code and cluster ID.
  4. The bot gives you a signed key and the plugin download.

What the key is tied to

Each key is signed offline and bound to the product, the game, your server machine (a machine code from Windows) and your cluster ID.

Moving servers

Use /license update when you move to a new machine or change your cluster ID. Moves have a 24-hour cooldown and a limit of 3 per year. Contact support if you need more.

Network use

Keys are checked offline on your server, so the plugin makes no network connections today. Each update carries a list of revoked keys (for example after a chargeback). Plugins fail open, so a licence problem never takes your server down. If we ever add an online revocation check, we will say so here first.

No trials

Try our free plugins to see how our plugins perform. Questions before buying? Open a ticket on Discord.
