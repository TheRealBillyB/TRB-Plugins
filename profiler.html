Profiler

TRB_PluginProfiler

Low-overhead sampling profiler that shows which plugins cost game-thread time, cause hitches, or burn CPU in their own threads.

Features

  • Charges each sample to the plugin DLL, ArkApi, or the game/engine, so you see which plugin costs frame time.
  • Designed so the profiler itself has no measurable effect on frame time or world saves.
  • Records every world save's duration and attributes hitches that contain a save to "World save".
  • Watchdog lowers the sample rate or disables sampling if its own work gets slow; re-enable with perf enable.
  • Background plugin threads are attributed by CPU time and never suspended.
  • Results show only on the admin's own screen (notification, MOTD panel or private chat); RCON and console get full plain text.
  • Writes report.txt / report.json on demand.

Commands

perf [minutes]Summary for the last N minutes
perf hitches [n]Recent hitches and their cause
perf suspends [min]Sampler pause histogram and watchdog info
perf savesWorld save durations
perf reportWrite report.txt / report.json now
perf reset / enable / demo / helpReset stats, re-enable after watchdog, colour preview, help

Configuration

Command name is configurable (CommandName, default perf). Display mode, colours, scale, line limits and sampling/watchdog settings live in ArkApi/Plugins/TRB_PluginProfiler/config.json; reload with plugins.unload/plugins.load.
