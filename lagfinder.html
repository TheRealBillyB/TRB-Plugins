LagFinder

TRB_LagFinder

Find the places on your map that make the server lag: one admin command scans every live actor and ranks hotspots and tribes.

Features

  • Scans structures, turrets, crop plots, storage, tamed/wild/baby dinos, eggs, dropped items, death bags, bodies and players.
  • Shows the heaviest hotspots (map cells with lat/lon, owner tribe, counts per kind) and the heaviest tribes.
  • Severity colours: red = heavy, orange = moderate, white = normal.
  • Writes the full report to report.txt and report.json; teleport straight to a hotspot with lagfinder tp <#>.
  • Read-only: changes nothing in the world. Output is on-screen only, never public chat.
  • Scans in tiny time slices (0.4 ms per tick by default), pauses during world saves, and does nothing when idle.

Commands

lagfinderLast fresh result, or start a scan
lagfinder scan / stopStart or cancel a scan
lagfinder summary / top / tribes / classesResult views
lagfinder cell <#> / tribe <id|name>Details for one hotspot or tribe
lagfinder tp <#>Teleport above a hotspot (in game)
lagfinder report / stats / demo / selftest / helpReport, scan cost, preview, checks, help

Configuration

Command name configurable (CommandName). Slice budget (SliceBudgetMs), optional scheduled scans (ScheduledScanMinutes), teleport toggle and severity thresholds are in config.json.
